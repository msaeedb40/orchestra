# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Orchestra, please send an email to the security team or open a private advisory on GitHub.

Please include:
- Description of the vulnerability.
- Steps to reproduce or proof of concept.
- Affected components and versions.
- Potential impact.

We will acknowledge receipt within 48 hours and work on a coordinated disclosure.
